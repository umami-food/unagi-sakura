# 炭火うなぎSakura 公式サイト

昼の業態「炭火うなぎSakura」（名古屋駅・柳橋フードマーケット4F）の公式サイトです。
夜の「和牛すき焼きしゃぶしゃぶSakura 名古屋店」のサイト（umami-food/sakura-site）と同じ仕組み（Astro・GitHub Pages・5言語）で作っています。

- 公開URL：https://umami-food.github.io/unagi-sakura/
- 店舗情報：src/data/site.json
- お品書き：src/data/menu.json
- 文言（5言語）：src/data/i18n/
- デザイン：src/styles/global.css（先頭の :root で色を変更）
- 写真：public/images/（同じファイル名で差し替え）
  - unadon.jpg（うな丼）、hitsumabushi.jpg（ひつまぶし・仮）、charcoal.jpg（炭火焼き・仮）、og.jpg（SNS用）
